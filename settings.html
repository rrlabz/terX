🔒 Security Details
Credential Encryption AES-256-CBC

All saved passwords are encrypted at rest using AES-256-CBC with a unique 256-bit key and per-entry random initialization vectors (IV). Credentials are never stored in plain text.

Encryption Key Protection OS-LEVEL

The master encryption key is protected by the operating system's native credential store:
• Windows: DPAPI (Data Protection API) — only the current Windows user account can decrypt it.
• macOS: Keychain — protected by your login credentials and Secure Enclave.

Local-Only Storage OFFLINE

All connection profiles, passwords, and settings are stored locally in the application data directory. No credentials are transmitted to any remote server, cloud service, or third-party API.

Network Security

SSH connections are established using your system's native OpenSSH client, inheriting your system's SSH configuration, host key verification, and known_hosts trust model. terX does not implement its own SSH protocol stack.

Export Security

Exported JSON files are always encrypted. By default, they are encrypted with your machine-bound OS key (DPAPI or Keychain), making them safe for local backups but unreadable on other devices. You can optionally provide a Transfer Password during export to securely encrypt the file with PBKDF2 for cross-machine portability.
